Examples

Debian security tracker: adds CVEs Debian hasn't fixed yet, with Debian's urgency. Releases default to the ones your hosts run.

releases: [bookworm, trixie]
include_unimportant: false

Alpine secdb: URL like https://secdb.alpinelinux.org/v3.21/community.json, no options needed.

OSV-format feed: a .zip, JSON list, NDJSON, or a local directory of OSV records (GHSA export, your own advisories).

path: /srv/advisories     # instead of a url (config.yml only)
ecosystems: [npm, PyPI]   # only keep these
headers: {Authorization: "Bearer …"}

Custom JSON / YAML / CSV: map your feed's fields to diysca's.

format: json              # json | yaml | csv
records: data.advisories  # where the list is
fields:
  id: advisory_id
  aliases: cves           # list or "CVE-1, CVE-2"
  package: product.name
  ecosystem: product.ecosystem
  fixed: fixed_in         # or versions / last_affected
  introduced: since
  severity: severity      # critical / high / ...
  cvss: score             # number or CVSS:3.x vector
  summary: title
defaults:
  ecosystem: "Debian:12"  # when the feed has no ecosystem

EPSS: exploit probability per CVE, shown on findings. No options needed.
